Comment créer un exercice

1. Sélectionnez la Discipline (CE, CO, Grammaire, Lexique).

2. Remplissez les informations de base : Niveau, Thème, et N° exercice.

3. Pour la compréhension écrite (CE) : Saisissez le texte principal, le titre et éventuellement la source.

4. Pour la compréhension orale (CO) : Chargez le fichier audio.

5. Ajoutez le type de questions souhaité : QCM, Vrai/Faux, ou Exercice Cloze (pour CO).

6. Cliquez sur "Ajouter à la banque".

7. Téléchargez votre fichier questions.json ou questions.js pour l'utiliser hors ligne.
