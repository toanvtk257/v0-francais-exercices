Comment créer un exercice

1. Sélectionnez la Discipline (CE, CO, Grammaire, Lexique).

2. Remplissez les informations de base : Niveau, Thème, et Titre.

3. Pour la compréhension écrite (CE) : Saisissez le texte principal, chargez une image ou collez depuis le presse-papier.

4. Pour la compréhension orale (CO) : Ajoutez le fichier audio local et éventuellement la transcription.

5. Ajoutez les questions avec leurs options et réponses correctes.

6. Cliquez sur "Sauvegarder l'exercice" pour l'enregistrer dans la base de données.
