📚 Guide d'utilisation

Plateforme d'exercices de français - Système de points

🎯 Comment ajouter des points aux questions

1 Ouvrez builder.html dans votre navigateur

Double-cliquez sur le fichier builder.html pour l'ouvrir dans votre navigateur web.

2 Utilisez l'onglet "Formulaire (Recommandé)"

Cet onglet est actif par défaut. Il offre une interface simple pour créer des exercices.

3 Remplissez les informations de base
  • Discipline: Lecture ou Écoute
  • Type d'exercice: QCM, Vrai/Faux, ou Cloze
  • Niveau: A1, A2, B1, B2, C1, ou C2
  • Thème: ex. "Salutations"
  • Titre: ex. "Leçon 01 - Bonjour"
4 Ajoutez des questions

Cliquez sur le bouton + Ajouter une question QCM ou + Ajouter une question Vrai/Faux

Un formulaire apparaîtra pour chaque question.

5 ⭐ DÉFINISSEZ LES POINTS ⭐
C'EST ICI QUE VOUS AJOUTEZ LES POINTS !

Dans chaque formulaire de question, vous verrez un champ "Points" en bas à droite.

Par défaut, il est réglé sur 1. Vous pouvez le changer à n'importe quel nombre (2, 3, 5, 10, etc.)

Exemple de formulaire QCM:

Question: Quelle est la capitale de la France ?
Choix A: Paris
Choix B: Lyon  
Choix C: Marseille
Bonne réponse: A
Points: [2] ← Changez ce nombre !
6 Ajoutez plus de questions

Répétez l'étape 4-5 pour ajouter autant de questions que nécessaire. Chaque question peut avoir un nombre de points différent.

7 Enregistrez dans la banque

Cliquez sur Ajouter à la banque pour sauvegarder votre exercice.

8 Téléchargez le fichier JSON

Cliquez sur Télécharger questions.json pour obtenir votre fichier de questions.

📊 Système de points - Comment ça marche

Pour les étudiants:

  • Chaque question vaut un certain nombre de points (défini par vous)
  • Après avoir terminé un exercice, l'étudiant voit: "Score: 15/20 points (75%)"
  • Les statistiques montrent les points gagnés pour chaque tentative
  • Le tableau de bord affiche le score moyen en pourcentage

Exemples de notation:

  • Question facile: 1 point
  • Question moyenne: 2-3 points
  • Question difficile: 5-10 points

🔧 Méthode alternative: Importation en masse

Si vous préférez copier-coller plusieurs questions à la fois:

  1. Cliquez sur l'onglet "Importation en masse"
  2. Format QCM: Question ; choix A ; choix B ; choix C ; réponse ; points
  3. Format VF: Énoncé ; vrai|faux ; mots-clés ; points
  4. Les points sont le dernier élément de chaque ligne

Exemple d'importation en masse:

Quelle est la capitale de la France ? ; Paris ; Lyon ; Marseille ; a ; 2
La Tour Eiffel est à Paris. ; vrai ; tour eiffel|paris ; 3
Le Louvre est un musée. ; vrai ; louvre|musée ; 1

❓ Problèmes courants

Je ne vois pas le champ "Points"

Solution: Assurez-vous d'avoir cliqué sur + Ajouter une question d'abord. Le champ Points apparaît dans chaque formulaire de question.

Le builder ne fonctionne pas

Solution: Ouvrez le fichier builder.html directement dans votre navigateur (Chrome, Firefox, Edge). Ne l'ouvrez pas dans un éditeur de texte.

Mes points ne sont pas sauvegardés

Solution: Vérifiez que vous avez bien cliqué sur Ajouter à la banque avant de télécharger le JSON.

📁 Structure des fichiers

  • login.html - Page de connexion
  • dashboard.html - Tableau de bord étudiant
  • exercise.html - Interface d'exercice
  • admin.html - Panneau d'administration
  • builder.html - Créateur d'exercices (VOUS ÊTES ICI)
  • data/questions.json - Banque de questions

🎵 Ajouter des fichiers audio

Pour les exercices d'écoute:

1 Créez un dossier "audio"

Dans le même dossier que vos fichiers HTML, créez un nouveau dossier nommé audio

2 Placez vos fichiers MP3

Copiez vos fichiers audio (format MP3) dans le dossier audio/

Exemple: audio/a1_salutations_01.mp3

3 Référencez l'audio dans le builder

Quand vous créez un exercice d'écoute, entrez le chemin complet dans le champ "URL Audio":

URL Audio: audio/a1_salutations_01.mp3
4 Dans le panneau d'administration

Même principe: dans le champ "URL Audio", entrez audio/nom_du_fichier.mp3

Conseils pour les fichiers audio:

  • ✅ Utilisez le format MP3 (le plus compatible)
  • ✅ Nommez vos fichiers de façon descriptive: a1_salutations_01.mp3
  • ✅ Gardez les fichiers courts (2-5 minutes maximum)
  • ✅ Qualité recommandée: 128 kbps minimum
  • ✅ Incluez le niveau CEFR dans le nom du fichier

Structure recommandée:

votre-projet/
├── login.html
├── dashboard.html
├── builder.html
├── admin.html
├── data/
│   └── questions.json
└── audio/
    ├── a1_salutations_01.mp3
    ├── a1_salutations_02.mp3
    ├── a2_voyages_01.mp3
    ├── b1_actualites_01.mp3
    └── ...
💡 Astuce: Commencez par créer un exercice simple avec 2-3 questions pour vous familiariser avec l'interface. Vous pourrez ensuite créer des exercices plus complexes.
