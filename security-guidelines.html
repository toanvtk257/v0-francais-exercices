🛡️ Directives de Sécurité - Site Idécaf

✅ Mesures de sécurité implémentées

Le système dispose maintenant de protections multicouches contre les menaces courantes.

1. Row Level Security (RLS) - Base de données

Protection: Contrôle d'accès au niveau des lignes de la base de données.

  • ✅ RLS activé sur toutes les tables sensibles
  • ✅ Les utilisateurs ne peuvent voir que leurs propres données
  • ✅ Les admins ont des permissions spéciales contrôlées
⚠️ Action requise: Exécuter le script scripts/004_enable_rls_security.sql dans Supabase.

2. Protection XSS (Cross-Site Scripting)

Protection: Empêche l'injection de code malveillant dans les pages.

  • ✅ Fonction sanitizeHTML() pour nettoyer les entrées
  • ✅ Fonction escapeHTML() pour échapper les caractères spéciaux
  • ✅ Content Security Policy (CSP) dans les headers HTML

Utilisation:

import { sanitizeHTML } from './lib/security.js';
const safeText = sanitizeHTML(userInput);
element.textContent = safeText; // Utiliser textContent, pas innerHTML

3. Rate Limiting (Protection Force Brute)

Protection: Limite les tentatives de connexion répétées.

  • ✅ Maximum 5 tentatives échouées en 15 minutes
  • ✅ Blocage temporaire automatique
  • ✅ Tracking côté client et serveur

4. Validation des Données

Protection: Vérification de toutes les entrées utilisateur.

  • ✅ isValidEmail() - Valide les formats email
  • ✅ isValidPIN() - Valide les codes PIN (4-6 chiffres)
  • ✅ isValidPhone() - Valide les numéros de téléphone
  • ✅ sanitizeInput() - Nettoie les inputs génériques

5. Sécurité des Headers HTTP

Protection: Headers de sécurité dans toutes les pages HTML.

  • ✅ Content-Security-Policy - Contrôle les sources autorisées
  • ✅ X-Content-Type-Options: nosniff - Empêche le MIME sniffing
  • ✅ X-Frame-Options: DENY - Empêche le clickjacking
  • ✅ X-XSS-Protection - Protection XSS du navigateur

6. Bonnes Pratiques à Suivre

⚠️ Important:
  • Ne jamais logger de données sensibles (mots de passe, PINs)
  • Toujours utiliser textContent au lieu de innerHTML pour du texte utilisateur
  • Valider toutes les entrées côté client ET serveur
  • Garder Supabase et toutes les dépendances à jour
  • Utiliser HTTPS en production (obligatoire)
  • Sauvegarder régulièrement la base de données

7. Monitoring et Alertes

Surveiller ces événements suspects:

  • Tentatives de connexion échouées répétées
  • Accès à des ressources non autorisées
  • Modifications de données inhabituelles
  • Requêtes SQL/XSS dans les inputs
✅ Checklist de Déploiement Sécurisé:
  • ☐ Exécuter le script SQL RLS
  • ☐ Importer lib/security.js dans tous les fichiers
  • ☐ Remplacer les innerHTML par textContent
  • ☐ Ajouter les meta tags de sécurité dans toutes les pages HTML
  • ☐ Tester le rate limiting
  • ☐ Vérifier que HTTPS est activé
  • ☐ Supprimer tous les console.log de debug en production
